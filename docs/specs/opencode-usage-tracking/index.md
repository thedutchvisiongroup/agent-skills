# OpenCode Usage Tracking

Functional Technical Design and implementation tasks for the OpenCode usage-tracking plugin.

* [FTD v1.0](ftd-v1.0.md) - Plugin-based real-time usage and cost telemetry for OpenCode sessions: event-stream logging (JSONL) plus derived session aggregates covering models, providers, token breakdown, tool statistics, active agent time, and recursive subagent usage.
* [Implementation tasks](tasks.md) - Grouped implementation batches mapped to FTD user stories, each with its own Definition of Done.
